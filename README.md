# Homebrew tap for NotifyAI

```sh
brew install windmill10/notifyai/notifyai
notifyai-collector list-apps
notifyai-collector install --allow-app BUNDLE_ID
```

The formula builds [NotifyAI](https://github.com/Windmill10/NotifyAI) from source
and needs Swift 6.1+ (Command Line Tools or Xcode 16.3+). See the main
repository for setup, Full Disk Access, and agent registration.
